# CMP 90HX compute + PCIe Gen2 (VBIOS 94.02.74.00.07)

Everything below was generated by AI, but the result was confirmed.

## Repos

| What | Where |
| --- | --- |
| Compute | [pearlfortune/cmpunlocker](https://github.com/pearlfortune/cmpunlocker) 90HX stockflow, NVIDIA Open **610.43.03**, patches `0001`–`0015` |
| PCIe on `.01` / `.05` | jdowning100 rejoin16 (`0016`) |
| PCIe on **`.07`** | this repo (`0017`) |

This card is `.07`. For `.01` / `.05`, use jdowning100.

## Unlock

### 1. Compute — pearlfortune

Install NVIDIA Open 610.43.03, then their 90HX stockflow (`0001`–`0015`). That opens FEAT and sets SS0/SS1.

On this card, locked FP32 was about **0.72 TFLOPS**. After stockflow it was in the mid-teens. Compute stays unlocked after reboot if the patched modules are installed.

### 2. PCIe Gen2 — rejoin16 + `0017`

Get NVIDIA’s `NVIDIA-kernel-module-source-610.43.03`, apply pearlfortune `0001`–`0015`, jdowning100 `0016`, then this patch:

```sh
patch -p1 < patches/0017-6104303-cmp90hx-vbios07-pcie-gen2.patch
cd kernel-open
MAKEFLAGS='CC=gcc-14' make -j"$(nproc)" modules
```

Install the five `nvidia*.ko` files:

```sh
sudo install -m644 nvidia.ko nvidia-uvm.ko nvidia-modeset.ko nvidia-drm.ko nvidia-peermem.ko \
  /lib/modules/$(uname -r)/updates/cmpunlocker-90hx-stockflow/
sudo depmod
```

After a **cold boot**, PCIe masks lock again. Run this once per power cycle:

```sh
gcc -O2 -o scripts/bar0rw scripts/bar0rw.c
sudo scripts/cmp90hx-gen2-consume.sh    # ~34 driver reloads
sudo scripts/cmp90hx-gen2-hammer.sh     # retrain until Gen2, then exit
```

If that hangs, power the box off for a minute. Do not loop FLR.

```sh
cat /sys/bus/pci/devices/<BDF>/current_link_speed    # 5.0 GT/s PCIe
sudo setpci -s <BDF> CAP_EXP+12.w                    # 1042 = Gen2
```

Do not write LnkCap. Do not use the 170HX `PL_LINK_RATE` value `0x00240036`. Leave Secure Boot off.

`systemd/` has optional boot units. Fix the `ExecStart` paths before enabling. Run consume before the hammer on cold boot.

## Notes

This machine’s slot is physically x16, split to x8 in BIOS; the card still trained x4. Some 90HX already do x16. Two cards: same unlock on each.

If BAR0 reads `0xffffffff`, cold reboot. Don’t toggle Link Disable with the driver loaded.
